운항 로그

이 데모는 발표·시연용 프로토타입입니다. 지도는 OpenStreetMap의 실제 지리 데이터를 사용하지만, 풍속·난기류·시정·지형고도·위험지수는 실제 기상청 API가 아닌 절차적으로 생성한 시뮬레이션 값입니다. "실시간 API 수신"이라는 표현은 시뮬레이션상의 주기적 데이터 갱신을 의미합니다. AI(Claude)는 산출된 수치를 바탕으로 조언 문장만 생성하며, 경로 자체는 A* 알고리즘이 결정합니다. 실서비스화 시에는 기상청 API허브(항공기상)와 국내 지형 데이터(V-World 등) 연동이 필요합니다.
